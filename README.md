# Achraf Rahibe | Engineering Portfolio

Personal engineering portfolio covering UAV/UAS, UGV, USV and avionics work.

## Publish on GitHub Pages

1. Create the public repository HRAFRH/hrafrh.github.io.
2. Upload this folder's contents to its main branch.
3. In Settings > Pages, choose Deploy from a branch, main, folder /docs, then Save.
4. Wait for GitHub Pages to finish publishing before sharing https://hrafrh.github.io/ on LinkedIn.

## Update projects

Edit content/projects.json and content/papers.json. Add real, matching photographs to docs/assets/.
Keep image fields empty until an actual project photograph is available.
Run python build_portfolio.py and commit the updated docs files.
Keep project IDs stable so shared project links continue to work.

## Content boundaries

Only public portfolio material is included. No account conversation exports, private engineering files, raw flight logs, application tracker or employer emails are part of this repository.
Concepts, review work and physical validation are labelled separately.

Design direction was inspired by Niko Weaver's personal portfolio. All project copy and user photographs are Achraf's own portfolio material.
