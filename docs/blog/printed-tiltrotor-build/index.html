From printed structures to a tiltrotor test platform

A V-tail tricopter VTOL brought mechanical assembly and flight-control configuration into the same development loop.

Achraf RAHIBE · 28 October 2026 · Project retrospective

The challenge: connect the moving mechanisms

A tiltrotor adds a mechanical interface to the control problem. The structure, propulsion units, servos and sensors have to work as a coordinated system. My work covered printed components and assembly as well as the electronics and autopilot setup.

Use a matching test configuration

I integrated the propulsion, servos and sensors and worked with Pixhawk-family and SpeedyBee ArduPilot configurations. A matching tricopter setup helped investigate settings before wider VTOL testing. This kept configuration work tied to the actual propulsion arrangement rather than treating the aircraft as a generic multirotor.

What reached testing

The project record includes assembly, hovering and maiden-test material, alongside mission-planning and configuration work. The photographs and system overview show the development stages. They describe a working development effort, with test scope kept separate from any claim of production qualification.
