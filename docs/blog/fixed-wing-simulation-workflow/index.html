Testing a fixed-wing mission in simulation

Mini Talon, Gazebo, ArduPlane and QGroundControl.

Achraf RAHIBE · Project retrospective

Set up the virtual aircraft

I configured the Mini Talon model and a virtual runway in Gazebo. The simulation connected to ArduPlane and QGroundControl so the aircraft model and mission workflow could be considered together.

Prepare the mission

The work included AUTO-mode waypoint missions and parameter checks. This provided a repeatable environment for examining mission preparation before physical flight work.

Keep simulation results in context

The delivery was a simulation and mission-testing workflow. A successful simulated mission is not physical flight-test evidence.

Project record

Results belong to simulation. They are not presented as physical flight-test evidence.
