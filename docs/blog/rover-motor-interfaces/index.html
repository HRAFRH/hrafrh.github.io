Connecting an autopilot to rover motor control

CUAV X7, dual VESC and ArduRover integration.

Achraf RAHIBE · Published 26 October 2026 · Project retrospective

Project photo to be added

Connect the control chain

My work linked the CUAV X7 autopilot, ArduRover configuration and dual VESC motor-control interfaces. The focus was the path between commanded vehicle motion and the motor controllers.

Keep the system view

Motor control also depends on the communication and configuration around it. I worked on those interfaces alongside broader coordination and docking concepts.

Identify the delivered scope

The delivered work covered motor-control integration and platform configuration. Docking and coordination remained concept work, rather than an operational autonomous service.
