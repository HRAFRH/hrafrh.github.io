Making a compact INAV FPV build ready for flight

A 3-inch platform connected power, radio control and firmware setup in a small airframe.

Achraf RAHIBE · 28 October 2026 · Project retrospective

The challenge: small aircraft still need full integration

Compact FPV aircraft leave little room for poor component placement or unclear wiring. This project brought together a 4S power system, flight-control electronics and ExpressLRS radio control within a small frame.

Bring the interfaces into one setup

I worked through the wiring, firmware configuration and control setup, including Angle and Horizon mode tuning. The objective was a coherent stabilized FPV configuration, with radio and flight-control behaviour checked together.

The delivered scope

The project record includes the build, documented wiring and flight-validation work for stabilized FPV flying. Its role is different from the autonomous mission platforms elsewhere in the portfolio. Keeping it separate makes the compact-aircraft integration work easier to see.

Project record

Published project scope covers stabilized FPV flying. Autonomous mission performance or heavy-payload capability is not claimed.
