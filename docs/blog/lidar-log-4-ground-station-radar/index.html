Lidar build log, part 4: a lidar radar inside QGroundControl

15 November 2026. Data on the flight controller is only half the job: the pilot has to see it.

Achraf RAHIBE · Project retrospective

Why QGroundControl showed nothing

Stock PX4 only sends OBSTACLE_DISTANCE to the ground station while Collision Prevention is running, which needs Position mode and GPS. A small MAVLink patch sends the raw scan whenever Collision Prevention is idle and streams it on USB at 10 Hz.

A radar without rebuilding QGroundControl

QGroundControl loads its Fly view instrument from a file named in its settings, and accepts a local file. The radar is a QML instrument dropped in that way: front up and aligned with the flight controller's arrow, red inside CP_DIST, yellow up to twice that, green beyond, the closest distance per side, the vehicle icon from the vehicle type and a warning when data stops. It can be moved, resized and opened full screen.

A desktop radar for the bench

A Python app finds the flight controller's USB port by itself and shows the same scan with direction cards and parking-sensor beeps. It also works next to QGroundControl through MAVLink forwarding.

Project record

Scope: PX4 driver and patches, ground-station displays and bench integration on two flight controllers. Collision Prevention in flight has not been tested yet.
