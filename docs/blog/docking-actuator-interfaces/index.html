Building the interfaces for a drone-to-rover dock

Actuators, isolated power and autopilot trigger logic.

Achraf RAHIBE · Project retrospective

Start at the mechanism

The docking architecture used four synchronized actuators. I developed the motor-driver and isolated power interfaces needed to connect that mechanism to the rest of the system.

Connect the trigger logic

The integration path combined CUAV X7+ AUX and RC-PWM interfaces with sensor inputs and MAVLink handshakes. This made the control handoff an explicit part of the proof of concept.

Separate the dock from full autonomy

The result was a docking proof of concept and an integration path. It was not evidence of an autonomous moving-rover landing or delivery service.

Project record

Owner-confirmed end-to-end development and system testing. The four-actuator docking mechanism and its staged integration are documented separately within the system work.
