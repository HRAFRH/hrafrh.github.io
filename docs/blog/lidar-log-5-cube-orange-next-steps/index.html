Lidar build log, part 5: the same driver on a Cube Orange Plus, and what comes next

15 November 2026. A second flight controller, and the plan to the first flight.

Achraf RAHIBE · Project retrospective

Port it to the Cube Orange Plus

The Cube Orange Plus showed the same boot-time rail switching in its PX4 board code, so it received the same kind of patch. Built for the Cube, the firmware uses 99.4 percent of flash. On the Cube, TELEM2 is a different serial device, and the lidar streamed at 22 Hz with no errors, including after a cold start.

Two boards side by side

Both flight controllers now run the same driver and the same displays. The differences are the build variant, the flash left, the serial device behind TELEM2 and the 5 V rail on USB, which is even lower on the Cube at 4.14 V. The project page compares them in one table.

What comes next

Fit a BEC for the lidar, mount it level and clear of the props, and test Collision Prevention outdoors in Position mode with the props off first. In parallel, run software-in-the-loop simulation with a simulated RPLidar to tune stopping distance and behaviour, then the first flight tests. This log continues with each step.

Project record

Scope: PX4 driver and patches, ground-station displays and bench integration on two flight controllers. Collision Prevention in flight has not been tested yet.
